# Генератор пакета документов

**Template Process Web** - веб-приложение для автоматического формирования пакета документов
на государственную регистрацию программы для ЭВМ или базы данных в Роспатенте
от имени РУДН.

Автор заполняет одну форму - сведения об объекте, о себе, о подразделении - и скачивает
ZIP-архив с готовыми документами: уведомлениями, заявлением, согласиями, договором
об отчуждении исключительного права, рефератом и материалами для диска. Одни и те же
данные больше не нужно вручную переносить в десяток файлов.

> Вся обработка выполняется в браузере. Персональные данные (паспорт, СНИЛС, реквизиты)
> не отправляются на сервер - сервер только раздаёт статические файлы приложения и шаблонов.

## Возможности

- **11 встроенных шаблонов DOCX** - официальный комплект РУДН; форматирование Word
  (шрифты, таблицы, колонтитулы) сохраняется полностью.
- **Одна форма на весь пакет** - 29 полей в четырёх разделах; у каждого поля подсказка,
  куда попадает значение, и пример заполнения.
- **Автоматические вычисления** - ФИО полностью и с инициалами, разбор даты рождения,
  отметки [X] в бланке Роспатента, число экземпляров договора и др. (17 вычисляемых тегов).
- **Состав пакета перед скачиванием** - список файлов архива виден в нижней панели.
- **Проверки шаблонов** - скрипты гарантируют, что каждый тег шаблонов заполняется из формы
  и в готовых документах не остаётся незаполненных мест.

## Состав пакета

Для одного автора формируется 10 документов:

| № | Документ | Сколько файлов |
|---|---|---|
| 01 | Уведомление-заявка | 1 |
| 02 | Уведомление о создании РИД | 1 |
| 03 | Заявление о регистрации | 1 |
| - | Дополнение к заявлению | только при нескольких авторах: по листу на каждые 3 автора после первого |
| 04 | Согласие автора на указание сведений | на каждого автора |
| 05 | Согласие на обработку ПД (Роспатент) | на каждого автора |
| 06 | Согласие на обработку ПД | на каждого автора |
| 07 | Договор об отчуждении исключительного права | 1 |
| 08 | Реферат | 1 |
| 09 | Обложка для диска | 1 |
| 10 | Титульный лист листинга | 1 |

## Быстрый старт

Нужен Node.js 18.17 или новее.

```bash
npm install
npm run dev        # http://localhost:3000
```

В режиме разработки на странице есть кнопка «Заполнить демо-данными» - можно сразу
скачать тестовый пакет, не заполняя форму.

Сборка для публикации:

```bash
npm run build
npm run start
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер на http://localhost:3000 |
| `npm run build` | production-сборка |
| `npm run start` | запуск собранного приложения |
| `npm run lint` | ESLint |
| `npx tsc --noEmit` | проверка типов |
| `npm run check:templates` | генерация всех шаблонов на демо-данных: число файлов, нет ошибок и незаполненных тегов |
| `npm run check:tags` | полнота тегов: каждый тег шаблонов заполняется из формы или вычисляется, каждое поле формы используется |

## Как это устроено

```
форма (app/page.tsx)
  - контекст с вычисляемыми тегами   lib/context.ts
  - план пакета: какие файлы и с какими данными   lib/plan.ts
  - заполнение каждого шаблона       lib/docx.ts
  - ZIP-архив и скачивание           lib/package.ts
```

Состав пакета и поля формы задаются конфигурацией, а не кодом: чтобы добавить документ,
достаточно положить шаблон в `public/templates` и добавить строку в `config/templates.ts`;
поле формы - описать его в `config/fields.ts`.

### Структура проекта

```
app/

  layout.tsx, globals.css

  form/FormField.tsx    поле формы (текст, список, дата, многострочный текст)
  form/FormSection.tsx  карточка раздела
  Icons.tsx             иконки (lucide-react)

  templates.ts          манифест пакета: файл, название, стратегия, порядок
  fields.ts             поля формы, группы, подсказки, вычисляемые теги

  context.ts            вычисляемые значения
  plan.ts               планировщик пакета (чистая функция)
  docx.ts               заполнение шаблона
  package.ts            загрузка шаблонов, ZIP, скачивание
  form.ts, demo-data.ts создание формы, тестовые данные

scripts/                check-templates.ts, check-tags.ts
types/                  типы данных формы
```

### Шаблоны и теги

Теги в шаблонах записываются в синтаксисе docxtemplater: `{key_ria_title}`.

- **Общие поля** - `key_ria_<поле>`: `key_ria_title`, `key_ria_year`, …
- **Поля автора** - `key_ria_author1_*` (первый автор, заявление),
  `key_ria_authorX_*` (текущий автор в согласиях и цикле),
  `key_ria_authorX1_*`…`X3_*` (авторы на листе дополнения).
- **Цикл по авторам** - `{#key_ria_authors}…{/key_ria_authors}` в договоре и уведомлении
  о создании РИД: блок повторяется для каждого автора.

Каждый шаблон формируется по одной из стратегий (`config/templates.ts`):

| Стратегия | Поведение |
|---|---|
| `single` | один файл на пакет, авторы - через цикл |
| `per-author` | отдельный файл на каждого автора |
| `additional` | дополнение к заявлению: авторы 2…N группами по 3; при одном авторе не создаётся |
